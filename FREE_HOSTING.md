# Бесплатное размещение РССМП

Основной адрес: https://rssmp-3d-tour.github.io/.
Публичная сборка GitHub Pages содержит canonical, sitemap.xml и разрешение индексации. Поисковая выдача появляется после обхода поисковиками, не сразу после публикации. Изменения сборки вступают в силу только после размещения проверенного артефакта на сайте.

Сборка автоматически отклоняет служебные файлы и размер более 1 000 000 000 байт. Рабочие исходники и внутренние материалы нельзя переносить в репозиторий опубликованного сайта. Открытый репозиторий готового сайта нужен для GitHub Pages на GitHub Free. Отдельный приватный репозиторий исходников допустим; его видимость здесь не менялась. При переносе исходников в приватный репозиторий нужно отдельно проверить ограничения и настройки оплаты Actions, чтобы не включить платное использование.

Платные сервисы, дополнительные аккаунты для обхода лимитов, внешние скрипты, аналитика и CAPTCHA не добавляются. Защита доступности зависит от платформы; собственные WAF, ограничение запросов и DDoS-защита настраиваемыми правилами в этом варианте не подключены. Посетитель может сохранить открытые страницы и изображения.

GitHub Pages предусматривает мягкий лимит трафика 100 ГБ в месяц; необходимо следить за трафиком и уведомлениями провайдера. При превышении использовать согласованное с провайдером решение, не обходить лимиты. Пиковая нагрузка 1000 посетителей не гарантируется и ещё не проверена.

Резервирование: перед обновлением сохранить текущую рабочую сборку вне публикуемой папки; хранить исходники отдельно. Для отката повторно разместить предыдущую проверенную сборку. Реальное восстановление и доступность из сетей пользователей требуется проверить отдельно.

Поддомен существующего домена станции можно подключить без регистрации нового домена при наличии доступа к DNS. Это отдельная настройка; текущий адрес содержит github.io.
