# Проверки сайта

Нужны Python 3 и Node.js 22.22+ (ветка 22) либо 24.8+. HTML-валидатор закреплён на версии 11.21.0; старые Node.js 18/20 для проверок больше не подходят.

```bash
cd tests
npm install
npx playwright install chromium   # один раз, если браузер ещё не установлен
npm test
```

| Файл | Что проверяет |
|---|---|
| `server.mjs` | Локальный сервер: заголовки из `dist/.htaccess`, 404, редирект `/about` → `/about/` |
| `functional.mjs` | Меню, поиск, настройки, диалоги, галерея, фильтры, копирование адреса, 404, печать |
| `equipment.mjs` | Каталог из 12 записей, классы B/C и неуточнённые привязки, все разделы шести исходных карточек, изображения без плакатов, отсутствие подмены фото неизвестных моделей, обычная прокрутка, клавиатура и возврат фокуса, axe на 320–1366 px, доступ без WebGL |
| `tour.mjs` | 3D-тур: ориентация, сцены и точки, клавиатура, мышь, касание, pinch, эффект присутствия, гироскоп, полноэкранный режим, ошибки WebGL и загрузки, старая разметка, выход из VR (эмуляция), честное отображение режима, превью → тайлы, движок Photo Sphere Viewer с сайта (без CDN, WebGL 2, загрузка только видимых тайлов), экскурсия, ссылка на вид, кнопки масштаба, уменьшение движения. Режим (`demo` или `vehicles`, с двором станции или без) определяется по странице автоматически |
| `shots.mjs`, `shots-guide.mjs` | Скриншоты страницы тура для визуальной проверки (в `npm test` не входят): `node shots.mjs http://localhost:8095 папка` |
| `make-vehicles-variant.mjs` | Временная копия сайта с другими панорамами: `vehicles` — четыре разные **синтетические** панорамы без двора, проверяет, что у каждого класса показывается своя картинка; `demo` — только демонстрационные панорамы. `run-all.sh` проверяет обе копии. В `dist` не попадают |
| `audit.mjs` | 9 страниц × 9 разрешений: ошибки JS/CSP/сети, горизонтальный скролл, заголовки, axe-core |
| `words.mjs` | Слова в заголовках, которые шире своего блока |
| `modes.mjs` | Увеличенный текст, высокая контрастность, масштаб 200 % |

WebGL в автоматических тестах работает через программный рендер SwiftShader. Реальные GPU, iOS/Android, гироскоп, вибрацию и VR-гарнитуру эти тесты не заменяют.
