## 1. Что это за проект

- **Заказчик и тема.** Демонстрационный сайт Республиканской станции скорой медицинской помощи (ГБУ «РССМП», г. Грозный) с 3D-туром автомобиля скорой помощи.

- **Аудитория:** жители, сотрудники станции, комиссия.
- **Требуемый стиль:** официальный, спокойный, современный сайт медицинского учреждения. Тёмно-зелёная палитра, красный акцент номера 103, эмблема. Без рекламного пафоса и без признаков шаблонного «AI-дизайна».
- **История.**
  - Версии до v8 сделаны до Claude, **вероятно**, в ChatGPT: в проекте осталась папка `.openai/` с настройкой хостинга.
  - 24–25.09.2026 Claude провёл полный аудит и выпустил версии v9–v9.5.
  - Теперь проект передаётся обратно в ChatGPT.

## 2. Устройство проекта

Статический сайт без базы данных и серверного кода. HTML собирает Python-скрипт.

```text
rssmp-site/  (в архиве — папка rssmp-site-v9/)
├─ AGENTS.md                 правила для ИИ-агентов (Codex, ChatGPT, Claude)
├─ ПОДКЛЮЧЕНИЕ_GITHUB.md     ChatGPT, Codex, pull request, публикация
├─ .github/workflows/site.yml сборка и все проверки на каждый pull request; архивы сборок
├─ .claude/skills/           скиллы (методички SKILL.md)
├─ docs/                     разбор mos03 и черновики справочника (не публикуются)
├─ build_pages.py            генератор: все страницы, поиск, версии файлов по хэшу, robots/sitemap
├─ shell.html                общая оболочка: <head>, шапка, меню, подвал, диалоги
├─ home.html                 содержимое главной
├─ static/                   РЕДАКТИРУЕМЫЕ исходники
│  ├─ style.css              все стили (отформатирован, без минификации)
│  ├─ app.js                 меню, поиск, настройки доступности, галерея, фильтры, копирование адреса
│  ├─ tour-viewer.js         3D-тур: точки, карточки, экскурсия, гироскоп, VR, эффект присутствия
│  ├─ assets/                фото, эмблема, панорамы (.jpg + -preview.jpg) и tour-tiles/
│  └─ vendor/                ГОТОВАЯ сборка Photo Sphere Viewer + three.js (psv.js, psv.css, LICENSES.txt) — вручную не править
├─ vendor-src/               исходник сборки vendor: package.json (версии закреплены), entry.js, build.mjs
├─ source-assets/            не публикуется: эмблема 512 px, мастер-файлы панорам (panoramas/)

├─ beget.htaccess            исходник dist/.htaccess (заголовки безопасности, кэш, запреты)

├─ tests/                    автоматические проверки на Playwright (см. tests/README.md)
├─ AUDIT_REPORT.md           полный отчёт аудита v8 → v9.5: 40 дефектов, решения, замеры, вопросы
```

### Что уже есть на сайте

**Общие функции:**
- номера 103 и 112;
- памятка «Что сообщить диспетчеру»;
- контакты с копированием адреса и ссылкой на карту;

- настройки доступности: крупный текст, контраст, без анимации — хранятся только в `localStorage`;
- фильтр новостей;
- галерея с листанием клавишами;
- страница 404.

**Безопасность и приватность:**
- нет форм, cookies, аналитики, CDN и внешних шрифтов;
- CSP без `unsafe-inline`, задана и в `<meta>`, и в `.htaccess`.

**3D-тур `/tours/` (v9.5):**
- движок Photo Sphere Viewer 5.15.1 (MIT) на three.js 0.185.1, собран в локальный файл — без CDN;
- тайлы: сначала превью, затем только видимые фрагменты;
- перетаскивание с инерцией, колесо, масштаб двумя пальцами, клавиатура;
- нумерованные точки с карточками и списком;
- «Экскурсия» по точкам с проходом через дверь в салон;
- «Поделиться» — ссылка на вид `#сцена@поворот,наклон,угол`;
- автообзор, полноэкранный режим (в том числе iPhone), гироскоп;
- VR через WebXR (отдельная небольшая WebGL-сфера, потому что в PSV нет WebXR);
- «Эффект присутствия» (бывший «5D-режим»): звук, световые акценты, вибрация;
- озвучивание описаний;
- понятные сообщения при ошибках WebGL и загрузки;
- совместимость со старыми ссылками `#b-…` и `#c-…`.

**Два режима тура** (задаются в `TOUR_PANORAMAS` в `build_pages.py`; подробно, с кадрами и размытыми областями, — `BEGET.md`):
- **vehicles** — сейчас (с 09.10.2026). **Факт:** оба автомобиля станции сняты 09.10.2026; классы указал владелец (кадры 0067–0074 — C, 0075–0085 — B). Выбор «Класс B / Класс C», у каждого — двор станции, вид снаружи, медицинский салон: 6 сцен, 44 точки в версии v9.7. Отдельно отмечены боковые и задние двери, ступени, кабины и все различимые на панорамах медицинские сумки/укладки. Люди и номера машин размыты, метаданные и GPS удалены. Модели автомобилей, назначение и состав сумок не указываются до подтверждения станцией.
- **demo** — если файлы B и C совпадают или демонстрационные. Один демонстрационный тур: 2 сцены, 11 точек, на странице сказано, что это не съёмка станции. Точки демо-панорам — в `demoScenes` (`static/tour-viewer.js`).

## 3. Как собрать, проверить и опубликовать

```bash
# Демонстрационная сборка (индексация закрыта: robots Disallow + noindex)
python3 build_pages.py                      # для Beget (с .htaccess)
RSSMP_TARGET=github python3 build_pages.py  # для GitHub Pages (без .htaccess, с .nojekyll)

# Публичная сборка — ТОЛЬКО после утверждения домена и материалов станцией
RSSMP_PUBLIC=1 RSSMP_BASE_URL=https://УТВЕРЖДЁННЫЙ-ДОМЕН python3 build_pages.py

# Новые панорамы (исходники 2:1 в source-assets/panoramas/)
pip install Pillow && python3 make_panorama_variants.py

# Пересборка библиотек тура (нужны Node.js и npm)
cd vendor-src && npm install && npm run build

# Проверки (Node.js + Playwright + Chromium)
cd tests && npm install && npx playwright install chromium && npm test
bash tests/run-all.sh                        # полный прогон: сайт, затем копии: B/C без двора (синтетические панорамы) и демо-режим

# Сверка опубликованного сайта с dist
python3 check_deploy.py https://rssmp-3d-tour.github.io
```

Для просмотра нужен HTTP-сервер (например, `cd dist && python3 -m http.server 8080`): пути абсолютные (`/assets/...`). Через `file://` и из подпапки сайт не работает.

### Публикация

- **GitHub Pages.** Загрузить **содержимое** `dist` в корень репозитория `rssmp-3d-tour.github.io` — через веб-интерфейс по `GITHUB_PAGES.md` или через git. Удалить файлы, которых нет в новой сборке. Затем `check_deploy.py`.
- **Beget.** По `BEGET.md`: **полностью** очистить `public_html` и распаковать содержимое `dist`. Частичная замена уже приводила к смешанным версиям. Затем `check_deploy.py http://dexaur9j.beget.tech`. Для `.htaccess` результат DIFF ожидаем: сервер его не отдаёт.

## 6. Чего делать НЕЛЬЗЯ

Правила собраны из требований владельца и решений проекта. Нарушение любого из них — ошибка.

**Содержание и правда:**
1. Не выдумывать факты: статистику, имена сотрудников, модели приборов, отзывы, медицинские обещания. Нет данных — так и сказать.
2. Не выдавать демонстрационные панорамы за съёмку автомобилей станции и не убирать предупреждение о демо на странице тура в демо-режиме. В турах по реальной съёмке размывать номера машин и людей, удалять GPS и EXIF.
3. Не публиковать медицинские тексты (справочник, черновики карточек) без проверки врачом РССМП. На публичной части — никаких схем лечения и дозировок.
4. Не копировать тексты, фото и код mos03project.ru и asmp.mos03project.ru: они защищены авторским правом. Структуру брать можно, тексты пишем свои.
5. Не называть режим «5D»: утверждено название «Эффект присутствия». Не обещать одинаковую работу VR, гироскопа и вибрации на всех устройствах.
6. Не утверждать «всё проверено», если не проверены реальные устройства и опубликованный сайт.

**Функции:**

7. Не удалять без согласования:
   - номера 103 и 112, контакты, памятку пациенту;
   - настройки доступности, поиск, галерею;
   - оба класса автомобилей в коде, виды «снаружи» и «в салоне», точки;
   - полноэкранный режим, гироскоп, VR, эффект присутствия, экскурсию.

**Техника и безопасность:**

8. Не подключать CDN, внешние шрифты, аналитику, сторонние виджеты, cookies, формы. Все библиотеки — локально.
9. Не вводить React, WordPress, базу данных или CMS без доказанной необходимости.

## 8. Ключевые решения и причины

| Решение | Почему |
|---|---|
| Статический генератор на Python вместо CMS | Небольшой сайт, безопасность, работает на любом хостинге. Сборка воспроизводима |
| Версии файлов по хэшу содержимого (`?v=…`) | nginx Beget кэширует CSS/JS 7 дней и игнорирует `.htaccess` для них — без хэшей пользователи видели смесь версий |
| Photo Sphere Viewer вместо своего движка (v9.5) | Бесплатный (MIT), активно развивается (5.15.1, август 2026). Даёт тайлы для 8K-съёмки, кубические панорамы и видео 360°. Pannellum обновляется редко (2.5.7), Marzipano не обновлялся с 2022 года, A-Frame рассчитан на VR-шлемы, а не на обычные туры |
| `blob:` в CSP `img-src` | PSV загружает изображения через `fetch` и отдаёт их как `blob:` — это память страницы, а не сторонний источник |
| Демо-режим при одинаковых файлах B/C | Нельзя показывать один снимок как два разных автомобиля |
| «Эффект присутствия» вместо «5D» | Физический 5D невозможен в браузере; честное название |
| Индексация закрыта | Материалы не утверждены станцией |
| GitHub Pages для демо | Бесплатно, HTTPS из коробки. Но риски для официального сайта — см. раздел 5, п. 9 |

## 10. Известные риски и ограничения

- **Качество тура ограничено исходником.** Съёмка автомобилей станции — 8192×4096 (уменьшена с 15520×7760). Демо-панорамы шириной 1774 px выглядят мягко; они нужны только для демо-режима и на сайте сейчас не показываются.
- **Вес тура.** Шесть панорам по 7–10 МБ (полный JPEG нужен для VR) и тайлы. Посетитель без VR загружает превью и только видимые тайлы.
- **WebGL 2.** Тур требует WebGL 2: Safari до 15 и старые устройства увидят сообщение вместо тура.
- **Первая загрузка тура.** Движок весит 650 КБ (около 169 КБ со сжатием).
- **Доступ к GitHub из России** в 2026 году нестабилен. **Вывод** по данным OONI: в мае до 16 % неудачных подключений.
- **Beget.** Сайт на Beget остаётся в смешанной старой версии, пока владелец не загрузит v9.5.
- **Жест и программное движение камеры.** Любое программное движение камеры (стрелки, кнопки масштаба, перелёт к точке) отменяет незавершённую инерцию щипка или перетаскивания.
  - **Факт** (по коду Photo Sphere Viewer): `viewer.animate()` вызывает `stopAll()`, а тот обнуляет накопленное движение жеста.
  - **Факт** (Chromium с эмуляцией касаний): если нажать стрелку, пока страница занята, её анимация запускается после щипка и отменяет масштаб.
  - Для посетителя это почти незаметно; приоритет низкий.
  - Тест T12b теперь ждёт окончания загрузки и остановки вида, а не фиксированные 200 мс. Раньше он падал в режиме четырёх панорам на медленной программной отрисовке.
- **Тесты работают только локально.** Им нужны Node.js, Playwright и Chromium. **Вывод:** в песочнице ChatGPT без интернета их, вероятно, не запустить. Тогда изменения нужно проверять у себя или прямо указывать «не проверено запуском».
