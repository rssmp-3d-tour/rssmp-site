# Публикация сайта на GitHub Pages

Сайт будет доступен по адресу `https://ИМЯ.github.io`, где ИМЯ — имя нового аккаунта GitHub. Всё делается в браузере, программы устанавливать не нужно.

## Перед началом

- **Имя аккаунта** станет частью адреса сайта: только латиница, цифры и дефис. Правила GitHub запрещают выдавать себя за другую организацию. Если в имени будет «rssmp», согласуйте его со станцией.
- **Репозиторий будет публичным** (для бесплатного аккаунта это обязательно). Загружайте только файлы сайта из архива `rssmp-site-…-github-pages.zip`. Не загружайте исходный проект: в нём внутренние заметки, отчёт аудита и вопросы к юристу.
- **Доступность из России.** В 2026 году фиксировались сбои доступа к GitHub. После публикации откройте сайт **без VPN** через мобильный и домашний интернет.
- **Для официального сайта станции** этот вариант, вероятно, не подходит из-за закона 406-ФЗ (подробнее — в `AUDIT_REPORT.md`, раздел 11). Для демонстрации он годится.

## 1. Создайте аккаунт

1. Откройте https://github.com/signup.
2. Укажите почту, пароль и имя пользователя (ИМЯ). Подтвердите почту кодом из письма.
3. Включите двухфакторную защиту: аватар → Settings → Password and authentication → Enable two-factor authentication. GitHub может потребовать её для новых аккаунтов.

## 2. Создайте репозиторий

1. Нажмите «+» вверху справа → **New repository**.
2. **Repository name:** ровно `ИМЯ.github.io` — ваше имя пользователя и `.github.io`. Только в этом случае сайт откроется в корне адреса: ссылки сайта рассчитаны на корень, и в подпапке сломаются стили и картинки.
3. Выберите **Public**. README, .gitignore и лицензию не добавляйте.
4. Нажмите **Create repository**.

## 3. Загрузите файлы

1. Распакуйте на компьютере `rssmp-site-…-github-pages.zip`.
2. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
3. Перетащите в окно **содержимое** распакованной папки — файлы `index.html`, `404.html`, `style.css`, `app.js`, `tour-viewer.js`, `robots.txt`, `search-index.json` и папки `assets`, `vendor`, `about`, `contacts`, `gallery`, `news`, `patients`, `privacy`, `tours`. Не перетаскивайте саму распакованную папку.
4. Дождитесь, пока загрузятся все файлы (45, включая вложенные), и нажмите **Commit changes**.

Скрытый файл `.nojekyll` Windows может не показать и не загрузить — сайт работает и без него.

## 4. Включите GitHub Pages

1. Откройте в репозитории **Settings → Pages**.
2. В разделе **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**.
3. Через 1–10 минут на вкладке **Actions** появится зелёная галочка у «pages build and deployment».
4. Откройте `https://ИМЯ.github.io`.

## 5. Проверьте

- Откройте главную, «Пациентам», «3D-туры», «Контакты» и несуществующий адрес (должна открыться страница 404).
- Полная сверка из папки исходного проекта:

  ```bash
  RSSMP_TARGET=github python3 build_pages.py
  python3 check_deploy.py https://ИМЯ.github.io
  ```

  Все строки должны быть `SAME`.

## Обновление сайта

1. Соберите новую версию: `RSSMP_TARGET=github python3 build_pages.py` (папка `dist`).
2. В репозитории: **Add file → Upload files** → перетащите содержимое `dist`. Файлы с теми же именами заменятся.
3. Файлы, которых больше нет в новой версии, удалите в репозитории вручную.
4. Повторите проверку `check_deploy.py`.

## Чем GitHub Pages отличается от Beget

- Сервер не отдаёт защитные заголовки из `.htaccess`. Основная защита (CSP: запрет встроенных и чужих скриптов) задана тегом `<meta>` в каждой странице и проверена тестом F13. Запрет встраивать сайт в чужие страницы (`frame-ancestors`, `X-Frame-Options`) так задать нельзя.
- HTTPS включён автоматически: гироскоп, VR и системный буфер обмена будут работать.
- Лимит трафика — 100 ГБ в месяц (мягкий). При превышении GitHub может перестать отдавать сайт или связаться с владельцем.
- Демонстрационная сборка закрыта от поисковиков (`robots.txt` и `noindex`).

## Собственный домен (по желанию)

Settings → Pages → **Custom domain**: укажите домен и настройте DNS по инструкции GitHub. Затем соберите публичную версию: `RSSMP_PUBLIC=1 RSSMP_BASE_URL=https://домен RSSMP_TARGET=github python3 build_pages.py`.
